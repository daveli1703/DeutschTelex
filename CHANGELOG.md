# Changelog

## [0.8.0]

### Changed

- Modernized the native Win32 Settings window with clearer visual hierarchy
- Added per-monitor DPI scaling with compatibility fallbacks for Windows 10
- Enabled current Windows Common Controls visual styles

## [0.7.0]

### Added

- MIT License and license inclusion in release packages
- Deterministic property and long-stream transformation tests
- Same-window mouse/caret safety reset
- Compatibility and Phase 7 validation reports

### Changed

- Release validation now audits binary mitigations, dependencies, privacy, and paths

## [0.6.0]

### Added

- Windows application version metadata and release branding
- Reproducible Release x64 packaging workflow
- Portable Windows release package
- Per-user Inno Setup installer configuration
- Release documentation, dependency inspection, and artifact naming checks

## [0.5.0]

### Added

- Optional Visual Studio Code exclusion based on foreground executable identity

## [0.4.0]

### Added

- Native Settings window and persistent preferences
- Optional Start with Windows registration
- Toggle notification and `sz → ß` preferences

## [0.3.0]

### Added

- Native system-tray application
- Global `Ctrl+Alt+G` ON/OFF toggle

## [0.2.0]

### Added

- System-wide Windows keyboard integration
- Unicode input injection and recursion prevention
- Single-character typo checkpoint and Backspace restoration

## [0.1.0]

### Added

- Platform-independent deterministic transformation engine
